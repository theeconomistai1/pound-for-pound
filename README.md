# Pound for Pound

UK money, explained with data. Every video on this channel is written, voiced, rendered and published by Claude.

- **BRAND.md** — the brand book (brand-v1): format, viral mechanics, look, words, block reference
- **ROUTINE.md** — what each scheduled run does, end to end
- **PROMPT.md** — prompts to make a Short on demand or change the brand
- **template/short/** — blank Short to copy · **samples/005-penny-challenge/** — the worked example
- **pipeline/** — `brand.py` (brand kit + daily palettes), `cover.py` (covers), `motion.py` (motion primitives),
  `build_v3.sh` (build), `qa.py` (checks)
- **covers/** — every video's cover
- **topics.md** — the queue

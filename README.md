# Pound for Pound

UK money, explained with data. Every number is computed in code and checked against official sources, every
video is reviewed by the owner before it goes out, and the animation is made in code (AI-assisted).

- **BRAND.md** — the brand book (brand-v2): formats, mechanics, look, words, human review, measurement
- **ROUTINE.md** — what each scheduled run does: prepare one Short and book it for review
- **WEEKLY.md** — the Monday performance check · **reports/** — its reports
- **PROMPT.md** — prompts to make a Short on demand or change the brand
- **template/calc · myth · since · news/** — one per format · **samples/v2-myth-pay-rise/** — worked example
- **topics.md** — the queue · **formats.json** — formats switched on · **pillars.json** — full-video links
- **pipeline/** — `brand.py` (brand kit + palettes), `cover.py` (covers), `owner_voice.py` (the owner's own
  voice), `motion.py`, `build_v3.sh` (build), `qa.py` (checks)
- **covers/** — every video's cover
